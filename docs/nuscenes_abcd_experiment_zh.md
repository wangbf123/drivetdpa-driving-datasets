# DriveTDPA A–D 开环消融实验中文说明

本文面向中文读者，说明 `drivetdpa_abcd_nuscenes_20260930` 这一组 NuScenes 开环消融实验的**目的、方法、结果与结论**，并给出所有相关文件的入口。

## 1. 这是什么实验

DriveTDPA 是一个端到端自动驾驶决策与轨迹规划模型，输出遵循 **RAT 协议**：

```text
Reasoning（推理 think） → Action（动作，3 步） → Trajectory（轨迹，6 点 / 3 秒）
```

本组实验在 NuScenes 数据集上做**开环（offline）消融**，回答四个问题：

| 组 | 问题 |
|---|---|
| **A** | 在 SFT 基础上加偏好优化（物理约束 / 联合偏好 / VL-DPO）是否提升精度？ |
| **B** | 去掉 BEV 场景上下文、或用语音转写代理替代文本，会怎样？ |
| **C** | 中间的 Action 动作层对最终轨迹有没有独立价值？ |
| **D** | Talk2BEV 场景描述（结构化事实 + 自然语言）有没有用？ |

## 2. 数据与训练

- **切分**：按场景 scene-disjoint（无泄漏）——训练 **2523 样本 / 841 场景**，held-out **180 样本 / 9 场景**（day / night / rain 各 3）。
- **模型**：InternVL 3.5-1B（视觉 backbone 冻结，LLM/MLP 微调）。
- **训练**：A1 走 SFT（200 步，lr 1e-5）；A2/A3/A4 从同 seed 的 A1 checkpoint 继续偏好训练（200 步，lr 1e-6）。
- **评估**：greedy 解码（`do_sample=False`）；A 类跨 3 个训练 seed（42/17/23）汇报 mean±std。

## 3. 结果（核心发现）

### 3.1 行为塌缩：只学"前进"，不学"转弯"和"停车"

| 现象 | 数字 |
|---|---|
| 模型从不输出转向 | 全部 20 个 eval 输出 `VEER` **0 次**（raw_text 亦 0/3600） |
| 标签里明明有转向 | held-out 52/180（28.9%）、train 710/2523（28.1%） |
| 模型从不刹车 | GT 停车样本 y6 均值 0.44m，模型仍预测 11.3–14.3m 巡航 |
| 塌缩与场景无关 | 9 个 held-out 场景全部 100% 直行 |

### 3.2 主导误差是"不会刹车"，不是"不会转弯"

| 按 GT 行为类别分解 ADE | A1 | A2 | A3 | A4 |
|---|---|---|---|---|
| GT 刹车样本 (n=32) | **10.13** | **11.22** | **10.71** | **10.82** |
| GT 转向样本 (n=52) | 5.24 | 5.01 | 5.09 | 5.09 |
| GT 加速样本 (n=109) | 4.88 | 4.50 | 4.61 | 4.73 |

→ 超额误差几乎全部来自**停车样本**（ADE≈10–11m，约为均值 2 倍）。

### 3.3 A 类偏好消融：无精度增益（负结果）

| 配置 | ADE (m) | FDE (m) | Goal | parse |
|---|---|---|---|---|
| A1 SFT | **5.811±0.740** | 9.995±1.239 | 0.908 | 1.000 |
| A2 +Physics | 6.140±0.615 | 10.600±1.027 | 0.852 | 1.000 |
| A3 +JPO | 5.920±0.704 | 10.188±1.148 | 0.877 | 1.000 |
| A4 +VL-DPO | 5.989±0.862 | 10.283±1.441 | 0.879 | 1.000 |

⚠️ 逐样本 Wilcoxon 会误判"显著更差"；改用**场景感知检验**（n=9 场景配对 + cluster bootstrap）后 **A1–A4 不可区分**（p≥0.36，CI 跨 0）。差异仅 0.1–0.3m，远小于场景间标准差 3.21m。

### 3.4 B/C/D 消融

- **B**：去 BEV 后 parse 1.00→0.61、场景引用 1.00→0.51（**输出不再合规**），但轨迹精度不动 → BEV 是"合规性"必要输入。
- **C**：去掉 Action 层 ADE +22%（6.75 vs 5.53）→ 动作层有独立约束价值。
- **D**：Talk2BEV 精度无显著差异（p=0.702），价值同样在合规性。

## 4. 结论一句话

> 模型先学会格式和"前进"意图，但**尚未学会"何时转弯、何时停车"**；当前最大失效是**纵向（不会停车）**，其次是横向（不转向）。surrogate 偏好优化在该预算下无增益。
