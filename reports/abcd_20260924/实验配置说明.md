# 实验配置说明

| 编号 | 中文名称 | 输入条件 | 输出协议 | 目的 |
|---|---|---|---|---|
| A1 | SFT 基线 | 完整输入 | RAT | 训练基线 |
| A2 | 物理偏好优化 | 完整输入 | RAT | 检查物理平滑偏好 |
| A3 | JPO 偏好优化 | 完整输入 | RAT | 检查动作-轨迹一致性偏好 |
| A4 | VL-DPO 偏好优化 | 完整输入 | RAT | 检查视觉/场景证据偏好 |
| B1 | 图像-文本 | text-only | RAT | 去除完整场景条件 |
| B2 | 图像-语音 | speech transcript proxy | RAT | 语音转写条件试验 |
| B3 | 图像-文本+BEV | full | RAT | 恢复 BEV 的文本对照 |
| B4 | 图像-语音+BEV | full-speech proxy | RAT | 恢复 BEV 的语音对照 |
| C1 | R→T | 完整输入 | 仅轨迹 | 检查直接轨迹输出 |
| C2 | R→A→T | 完整输入 | RAT | 检查完整结构化协议 |
| D1 | 无 Talk2BEV | no BEV | RAT | Talk2BEV 移除对照 |
| D2 | 有 Talk2BEV | full BEV | RAT | Talk2BEV 完整条件 |

注意：B2/B4 是语音转写文本 proxy，不是音频编码器；C1 的指标主要反映轨迹解析，不等同于完整 RAT 推理链。
