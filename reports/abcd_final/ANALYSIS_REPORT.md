# DriveTDPA 开环实验 A–D 完整分析报告（最终版 v3）

> 数据：NuScenes v1.0-trainval scene-disjoint 切分（训练 2523 样本 / 841 场景；held-out 180 样本 / 9 场景，day·night·rain 各 3）
> 模型：InternVL 3.5-1B；SFT 200 步 lr1e-5，偏好训练 200 步 lr1e-6；评估 greedy
> 统计：A 类跨 3 seed（42/17/23）；配对 Wilcoxon（按样本对齐）+ 场景感知 cluster bootstrap
> 依据：《DriveTDPA 实验指导》"第二步：开环实验（NuScenes-TP）"（`/mnt/workspace/TEMP-FILE-STATION/DriveTDPA 实验指导.docx`）

---

## 0. 摘要

1. **surrogate 偏好优化（A2/A3/A4）相对 SFT（A1）无精度增益**；场景感知检验下 A1–A4 **统计上不可区分**（场景级 p≥0.36，95% CI 均跨 0）。注：逐样本 Wilcoxon 曾给出"显著更差"，但那是忽略场景聚类的**反保守假阳性**（见 §5）。
2. **模型发生"行为类别塌缩"**：丢弃了标签中 ~29% 的**转向动作**（全部 20 个 eval 输出 VEER 共 **0 次**），且几乎**从不刹车/停车**。
3. **主导误差源是"不会刹车"而非"不会转弯"**：GT 需停车样本 ADE ≈ **10.1–11.2m**（约为均值 2 倍），GT 需转向样本 ADE ≈ **5.0m**（接近均值）。
4. **BEV 决定输出合规性**（去 BEV：parse 1.00→0.61，场景引用 1.00→0.51），但不影响轨迹精度。
5. **动作层（Action）有独立价值**：去掉后 ADE +22%（6.75 vs 5.53）。
6. **模型"推理"是复述**：think 文本 8-gram 有 **85.4%** 能在输入里逐字找到，即复述 BEV 上下文而非推理机动决策。

> ⚠️ 与早期报告（`reports/abcd_按实验指导_20260930/`）的关系（诚实记录）：早期报告基于**单场景 20 样本 pilot**，其结论（"Talk2BEV 使 ADE 降 19.75%"、"C1 精度略优"、"A1–A4 差异 <0.5%"）在**全量 180 样本 + 场景感知统计**下被修正：D 组精度无显著差异、C 组去掉动作层反而恶化 +22%、A 组差异不显著。本报告是全量数据下的**定稿**，早期报告保留为历史记录。

## 1. 实验依据、目的与运行设置

### 1.1 依据与目的

按实验指导，在 NuScenes-TP 上开展 A–D 四组开环实验，分别回答：

| 组 | 实验问题 | 配置 |
|---|---|---|
| **A** | 在 SFT 基础上加入物理约束 / 联合规划 / 视觉语言偏好，是否提升轨迹精度？ | A1 SFT、A2 Physics、A3 JPO、A4 VL-DPO |
| **B** | 语音指令与 BEV 场景上下文如何影响结构化输出与场景理解？ | B1 图+文、B2 图+语音、B3 图+文+BEV、B4 图+语音+BEV |
| **C** | 动作层 A 对最终轨迹是否有独立价值？ | C1 R→T（去 A）、C2 R→A→T（完整） |
| **D** | Talk2BEV 场景描述是否改善规划与 grounding？ | D1 无、D2 有 |

### 1.2 运行设置

| 项目 | 设置 |
|---|---|
| 数据切分 | scene-disjoint（无泄漏）：训练 2523 样本 / 841 场景；held-out 180 样本 / 9 场景 |
| held-out 条件 | day / night / rain 各 3 场景（各 60 样本） |
| 轨迹格式 | 3 秒、6 个轨迹点（ego-centric x_right / y_forward） |
| 输出协议 | RAT：Reasoning（think）→ Action（3 步）→ Trajectory（6 点） |
| 训练 | A1 SFT 200 步 lr1e-5；A2/A3/A4 从同 seed A1 checkpoint 继续 TPO 200 步 lr1e-6 |
| 训练 seed | A 类每个配置 3 个（42/17/23）；B/C/D 用 A4 seed42 参考 checkpoint |
| 评估 | greedy（`do_sample=False`），`EVAL_MAX_NEW_TOKENS=1024` |

### 1.3 指标中文说明

| 指标 | 中文含义 | 判定方向 |
|---|---|---|
| ADE (m) | 平均位移误差：预测轨迹各点与参考轨迹的平均欧氏距离 | 越低越好 |
| FDE (m) | 最终位移误差：预测末端点与参考末端点的距离 | 越低越好 |
| ADE_worstcase | 解析失败样本按固定 10m 罚分的 ADE（`ADE_common` 反之） | 越低越好，反映"精度+可用性"联合 |
| Goal | 预测终点对驾驶任务（FORWARD）的奖励 | 越高越好 |
| A→T consistency | 动作（Action）与轨迹（Trajectory）方向一致性 | 越高越好，1.0 为全一致 |
| R→A consistency | 推理（Reasoning）与动作方向一致性 | 越高越好（仅 think 含显式方向时计分） |
| TMC | 轨迹-动作-语义链路一致性代理指标（当前≈A→T） | 越高越好 |
| parse_success_rate | 输出符合 RAT 结构、可抽取动作与 6 点轨迹的比例 | 越高越好 |
| scene_reference_rate | think 引用 BEV 标注场景实体的样本比例 | 越高越好 |
| Lat_ms_mean / p95 | 平均 / 95 分位推理延迟 | 越低越好 |

ADE/FDE 只衡量连续轨迹几何误差，**不能单独代表输出是否可执行**；本报告联合比较"轨迹精度 + 结构化可用性 + 场景 grounding + 延迟"。

## 2. 行为塌缩的三层证据

### 2.1 动作层：整类丢弃转向（决定性证据）

**标签里有，模型学不会**：

| | GT 标签（held-out 180） | GT 标签（train 2523） | 模型输出（20 个 eval） |
|---|---|---|---|
| 含转向 VEER | **52 (28.9%)** | 710 (28.1%) | **0 次** |
| 含刹车 DECELERATE | 32 (17.8%) | 632 (25.1%) | 仅部分 seed 出现 |
| 含加速 ACCELERATE | 109 (60.6%) | — | 主导 |

- 模型中**从未出现过 `VEER_LEFT` / `VEER_RIGHT`**：全部 20 个 eval、全部样本，输出 VEER 次数 = **0**。
- 模型动作词表退化为 `FOLLOW_LANE × {ACCELERATE, MAINTAIN, DECELERATE}`，**只有纵向、没有横向**。
- GT 含转向的 52 个样本，模型 **52/52 未转向**（100%）。
- 极端案例：A1 seed17 对全部 180 个样本输出同一条 `FOLLOW_LANE+ACCELERATE`。

### 2.2 横向：从不转向

| 末点横向位移 \|x6\| | GT | 模型 |
|---|---|---|
| 全体均值 | 1.047 m | 0.094–0.157 m |
| GT 含转向样本（n=52） | 均 3.24 / 中位 2.87 / **最大 9.98 m** | ≈ 0（<0.5m 占 100%） |
| GT 无转向样本（n=128） | 均 0.16 m | ≈ 0（正确） |

模型对**全部 180 样本**输出近零横向位移，完全忽略 52 个真实转向样本（中位 2.87m、最大近 10m 的转弯）。

### 2.3 纵向：从不刹车/停车（**比转向更严重**）

| 末点纵向位移 y6 | GT | 模型 |
|---|---|---|
| 全体均值 / 中位 | 16.31 / 16.55 m | 18.5–21.8 m（中位） |
| **GT 刹车样本（n=32）** | **均 0.44 / 中位 0.00 m**（真停车） | 均 14.3 / 中位 12.0 / **最小 11.3 m** |
| 模型 y6<3m 占比 | 17.8%（GT） | **≈ 0%**（seed42 上为 0 例） |
| 每 seed 纵向取值数/180 | 连续 | 17（A1s42）～75（A2s17） |

GT 中 17.8% 的样本要求车辆**停车**（y6≈0）；模型在这些样本上仍预测 11–14m 巡航，纵向误差 ~12–14m，ADE 高达 8–11m。**模型不会停车——这是首要失效模式。**

### 2.4 反证检验（排除分析 artifact）

| 检验 | 结果 | 意义 |
|---|---|---|
| 模型原始输出 `raw_text` 是否含 VEER | **0 / 3600** 条 | 排除"解析器丢弃转向"的 artifact——模型确实从不生成转向动作 |
| `raw_text` 是否被截断 | 否（示例 857 字符，完整含 trajectory 段） | 排除截断导致的漏计 |
| 伪标签 VEER vs 几何 \|x6\|>0.5 一致率 | 97.2%（held-out）/ 92.6%（train） | 伪标签可信；且偏保守（held-out 漏标 5 例、train 漏标 171 例）→ 模型失效比标签所示更严重 |
| 方向符号自洽 | VEER_RIGHT→x6>0（100%，均 +2.70m）；VEER_LEFT→x6<0（100%，均 −4.70m） | 验证坐标框架与 ADE 计算无误 |
| think 复述率普适性 | A1/A2/A4 三配置**完全相同**（0.854/0.883） | think 是**输入决定的拷贝**，不随训练权重变化 → 非推理 |

## 3. ADE 误差归因（按 GT 行为类别分解）

| 配置 | GT 转向 (n=52) | GT 无转向 (n=128) | **GT 刹车 (n=32)** | GT 加速 (n=109) |
|---|---|---|---|---|
| A1 SFT | 5.242 | 6.043 | **10.133** | 4.877 |
| A2 Physics | 5.009 | 6.599 | **11.222** | 4.497 |
| A3 JPO | 5.087 | 6.259 | **10.711** | 4.606 |
| A4 VL-DPO | 5.088 | 6.355 | **10.820** | 4.729 |

**结论**：ADE 的"超额误差"几乎全部来自**刹车样本**（ADE ≈ 10–11m，2× 均值）。转向样本 ADE ≈ 5m 仅略高于加速样本（≈4.5–4.9m），因为横向误差（中位 2.87m）远小于刹车样本的纵向误差（~12–14m）。**因此"提升转向"不是当前最高优先级，"学会停车/减速"才是。**

---

## 4. 为什么会这样（机制）

1. **少数类塌缩 + 边际先验复制**：ACCELERATE/巡航占标签多数（60.6%），VEER 仅 28.9%（且每样本仅 3 步中出现 1–2 步）。200 步短训 + 1B 小模型条件下，模型坍缩到多数类，整类丢弃转向、刹车。
2. **think 是复述而非推理**：think 有 **85.4%** 的 8-gram 逐字来自输入（复述 BEV 数字），模型把"证据"抄进 think，却**不让证据影响动作/轨迹**——BEV 中的 `risk=pedestrian_nearby` 样本照样输出 `FOLLOW_LANE, ACCELERATE`。这解释了"场景引用率 100% 但轨迹精度不动"。
3. **surrogate 偏好信号太弱**：A2/A3/A4 的 rejected 由本地构造，只教"别输出某种坏轨迹"，未提供正向的"如何转向/停车"示范；故偏好训练只增加了纵向**多样性**（唯一轨迹 30→73，前 3 轨迹占比 0.55→0.30），未恢复丢失的动作类。
4. **格式先学会、行为后学会**：parse=1.0、Goal≈0.9、A→T=1.0 说明 RAT 协议与"前进"意图先被学会，而"何时停、何时转"未被学会。

## 5. 实验 A：偏好优化消融（负结果）

### 5.1 实验问题

在相同数据与输出协议下，加入物理约束、联合规划（JPO）、视觉语言（VL-DPO）偏好后，模型能否在保持轨迹精度的同时扩展优化目标？

### 5.2 训练结果

| 配置 | 训练目标 | 训练步数 | train_loss（3 seed 范围） |
|---|---:|---:|---:|
| A1 SFT | 语言建模（SFT） | 200 | 0.121–0.129 |
| A2 Physics | TPO（物理平滑偏好） | 200 | 0.420–0.426 |
| A3 JPO | TPO（联合规划偏好） | 200 | 0.381–0.403 |
| A4 VL-DPO | TPO（视觉语言偏好） | 200 | **0.119–0.138** |

> 注：SFT 与 TPO 的损失函数不同，A1 与 A2–A4 不可直接比较；A2/A3/A4 同为 TPO，**A4 收敛到最低 loss（≈0.13），显著低于 A2（≈0.42）、A3（≈0.39）**，说明 VL-DPO 的偏好对最容易被模型拟合。

### 5.3 评估结果

| 配置 | ADE (m) | FDE (m) | Goal | parse | A→T | 场景引用 | Lat 均值 (ms) |
|---|---|---|---|---|---|---|---|
| A1 SFT | **5.811±0.740** | **9.995±1.239** | **0.908±0.047** | 1.000 | 1.000 | 1.000 | 11577±116 |
| A2 SFT+Physics | 6.140±0.615 | 10.600±1.027 | 0.852±0.043 | 1.000 | 1.000 | 1.000 | 11939±336 |
| A3 SFT+JPO | 5.920±0.704 | 10.188±1.148 | 0.877±0.047 | 1.000 | 1.000 | 1.000 | 11722±299 |
| A4 SFT+VL-DPO | 5.989±0.862 | 10.283±1.441 | 0.879±0.044 | 1.000 | 1.000 | 1.000 | 11714±118 |

**逐样本配对 Wilcoxon（ADE，n=180）**：A1vsA2 p=0.0011 d=−0.199；A1vsA3 p=0.0421 d=−0.113；A1vsA4 p=0.0024 d=−0.177 —— 表面上"显著更差"。

**⚠️ 但该检验反保守**：它把同一场景的样本当作独立观测，忽略场景聚类。改用**场景感知检验（n=9 场景配对 + cluster bootstrap，5000 次重采样）**：

| 对比 | 场景均差 (A1−其他) | bootstrap 95% CI | 场景级 Wilcoxon p | 结论 |
|---|---|---|---|---|
| A1 − A2 | −0.33 m | [−1.04, +0.42] | 0.570 | 不显著 |
| A1 − A3 | −0.11 m | [−0.48, +0.29] | 0.652 | 不显著 |
| A1 − A4 | −0.18 m | [−0.54, +0.21] | 0.359 | 不显著 |

**正确结论：A1–A4 在本实验规模下统计上不可区分**——差异仅 0.1–0.3m，远小于场景间标准差 3.21m。"偏好训练更差"不成立，应为**无差异**。论文若用逐样本检验会得到错误结论，**必须用场景感知统计**。

> 附录 A 中的 ±std 为跨训练 seed 的离散度，只反映训练随机性，不含场景不确定性；配置间正确的不确定性区间以上表 cluster bootstrap 为准。

### 5.4 机制与结论

偏好优化没有改变输入规模与生成协议，只改变对候选的排序倾向；且 surrogate 偏好只提供"负向"信号。因此三种偏好训练**均未恢复丢失的动作类，也未改变轨迹精度**，仅把纵向输出**多样性**提高了（附录 C：唯一轨迹 A1 30 → A2 73）。A4 虽收敛到最低 loss，但该"拟合"未转化为可测的精度或行为增益。

### 5.5 对论文的价值

- **可支撑**："surrogate 偏好优化 + 当前预算（200 步/1B）下无精度增益，A1–A4 不可区分"（负结果，须用场景感知统计）。
- **不可支撑**："偏好优化优于 SFT"（需真实 reward rollout + 更大预算，见 §13 W1）。
- **汇报口径**：A 组证明的是"训练目标可扩展但当前 surrogate 信号不足"，主对照用 A1 vs A4，并明确其为负结果。

## 6. 实验 B：输入模态消融

### 6.1 实验问题

语音指令能否参与规划？BEV 场景上下文对**结构化输出**与**场景理解**（而非轨迹精度）是否有决定作用？

### 6.2 数据对比

| 配置 | 输入 | ADE_common | ADE_worstcase | parse | 场景引用 | Lat (ms) |
|---|---|---|---|---|---|---|
| B1 Image+Text | 无 BEV | 5.694 | 7.393 | **0.606** | **0.511** | 13299 |
| B2 Image+Speech | 无 BEV | 5.652 | 5.797 | 0.967 | 0.744 | **6573** |
| B3 Image+Text+BEV | 有 BEV | 5.530 | 5.530 | **1.000** | **1.000** | 11495 |
| B4 Image+Speech+BEV | 有 BEV | 5.018* | 7.288 | **0.544** | **0.544** | 18871 |

（*B4 ADE 仅覆盖 54.4% 解析成功子集，不可与全量直接比较）

### 6.3 解析失败模式（为何去 BEV 会崩）

- **B1 / D1（无 BEV）**：71/180 样本解析失败。模型**幻觉出泛化叙述** "The BEV evidence shows a clear road ahead with no immediate hazards..."（无任何 BEV 数字），随后无法产出可解析的 6 点轨迹。
- **B4（语音转写 + BEV）**：82/180 失败。语音转写代理**破坏 RAT 格式**（复述 BEV 但格式错乱/截断），即便有 BEV，parse 仍 0.544。
- **B2（语音转写，无 BEV）**：parse 0.967 意外偏高、且 Lat 最低（6573ms）——语音转写短、解码快，但场景引用率仅 0.744。

### 6.4 机制与结论

**BEV 是 RAT 输出合规性的必要输入，而非轨迹精度的必要输入。** 去掉 BEV，parse 1.00→0.61、场景引用 1.00→0.51（合规性崩塌），但 `ADE_common` 几乎不动（B1 5.694 vs B3 5.530，仅 0.16m）。这印证 §4 的"think 是复述"：BEV 被抄进 think 以满足格式，但并未真正驱动转向/停车决策，故对轨迹精度影响微弱。语音转写代理是**破坏格式的风险源**（B4 parse 0.544），与 BEV 的"稳定格式"作用相反。

### 6.5 对论文的价值

- **可支撑**："BEV 是输出合规的必要输入"（parse/ref 证据），以及"语音转写代理会破坏格式"。
- **不可支撑**："BEV 显著提升轨迹精度"（`ADE_common` 差异仅 0.16m，不显著）。
- **汇报口径**：B 组的核心是"合规性"而非"精度"；文字+BEV（B3）是稳定首选，语音+BEV（B4）需真实音频编码器后再评估。

## 7. 实验 C：动作层消融

### 7.1 实验问题

直接从 reasoning 生成 trajectory（R→T），与先经过 action 再生成 trajectory（R→A→T）相比，动作层对轨迹精度是否有独立价值？

### 7.2 数据对比

| 配置 | 输出协议 | ADE (m) | FDE (m) | Goal | parse | A→T | Lat (ms) |
|---|---|---|---|---|---|---|---|
| C1 R→T | trajectory-only | **6.749** | 11.590 | 0.988 | 1.000 | 1.000 | 11717 |
| C2 R→A→T | 完整 RAT | **5.530** | 9.491 | 0.916 | 1.000 | 1.000 | 11742 |

### 7.3 机制与结论

去掉动作层后 **ADE 恶化 1.22m（+22.0%）、FDE 恶化 2.10m（+22.1%）**，且延迟几乎不变（+25ms）。这与早期 pilot（单场景）"C1 略优"的结论相反——在 180 样本下，动作层不是冗余文本，而是**对轨迹的独立约束**：它把"语义判断 → 离散动作 → 连续轨迹"显式分解，使轨迹生成受动作先验约束，防止 R→T 直接回归时的数值漂移。同时动作层是可审计、可接入安全门控与下游控制接口的中间表示。

### 7.4 对论文的价值

- **可支撑**："动作层独立贡献轨迹精度（+22%），且几乎无延迟代价"——这是 RAT 分层设计最直接的证据。
- **汇报口径**：C 组是 A/B/C/D 中**正向效应最明确**的一组，建议作为 RAT 结构的核心消融。

## 8. 实验 D：Talk2BEV 消融

### 8.1 实验问题

Talk2BEV 场景描述（结构化事实 + 自然语言）是否改善规划、grounding 与输出可靠性？

### 8.2 数据对比

| 配置 | ADE_common | ADE_worstcase | parse | 场景引用 | Lat (ms) |
|---|---|---|---|---|---|
| D1 no Talk2BEV | 5.694 | 7.393 | 0.606 | 0.511 | 13728 |
| D2 Talk2BEV | 5.530 | 5.530 | **1.000** | **1.000** | 12163 |

**配对 Wilcoxon（ADE，n=109 公共可解析子集）**：D1 vs D2 **p=0.702，d=−0.013** → **轨迹精度无显著差异**。

### 8.3 机制与结论

Talk2BEV 的价值**全部在合规性与 grounding**：parse 0.606→1.000（+35pp）、场景引用 0.511→1.000（+60pp）、`ADE_worstcase` 7.39→5.53（消除解析失败罚分）。但 `ADE_common` 仅 5.694→5.530（0.16m），不显著。这与早期 pilot 的"ADE 降 19.75%"结论相反——pilot 用 20 样本、且把 parse 失败样本的精度差异混入了 ADE。全量数据下：**Talk2BEV 让输出"可用且可审计"，但不让轨迹更准**（因为模型本就不做转向/停车，见 §2）。延迟上 D2 反而更低（12163 vs 13728ms），因为 BEV 抑制了无 BEV 时的幻觉长文本。

### 8.4 对论文的价值

- **可支撑**："Talk2BEV 是输出合规性与场景 grounding 的必要输入"（parse/ref/`ADE_worstcase` 证据）。
- **不可支撑**："Talk2BEV 显著提升轨迹精度"（p=0.702）。
- **汇报口径**：D 组与 B 组同源（D1=B1、D2=B3），应**合并陈述**为"BEV/Talk2BEV 决定合规性而非精度"。

## 9. 条件（day/rain/night）—— 不可作鲁棒性结论

| 配置 | day ADE | night ADE | rain ADE |
|---|---|---|---|
| A1 | 9.302 | 3.981 | 4.151 |
| A2 | 8.711 | 4.650 | 5.058 |
| A3 | 9.103 | 4.106 | 4.552 |
| A4 | 9.256 | 4.139 | 4.572 |

day 反而最差、night 最好。**量化的场景级证据**（A1 各场景 ADE）：day = {10.04, 9.85, 8.02}、night = {4.42, 4.29, 3.23}、rain = {8.94, 2.12, 1.39}。场景间标准差 **3.21m**，rain 组**内部极差 7.6m**；cluster bootstrap（按场景重采样）给出 A1 ADE 的 95% CI = **[3.71, 7.91]**（点估计 5.81m）。

**判断**：条件与场景**完全混淆**（每类仅 3 个场景），场景身份解释了大部分方差。**不得据此下"光照鲁棒性"结论**——只能说"这 9 个特定场景差异大"。需 ≥10 场景/类 + 场景随机效应模型。

## 10. 局限与边界（论文必须声明）

- 偏好对为 **surrogate**（非真实 reward rollout）→ 结论限于"surrogate + 当前预算无效"，不能推出"偏好优化本身无效"。
- 语音为**转写代理**，无真实音频编码器 → B2/B4 结论不适用于真实语音。
- 评估 **greedy** → 不含采样方差；A 类方差仅来自训练 seed。
- 训练 **200 步 / 1B** → 结论是"该预算下的塌缩"，非普适。
- `Unsup` 未算；`TMC` 为 A→T 代理；`R_to_A_consistency` 无方向标注时为 null。
- held-out 仅 9 场景 → 适合方向性消融，不适合绝对性能声明。
- **动作伪标签本身是启发式生成**（`actions_are_pseudo_labels: true`）→ "模型不输出 VEER"是相对该伪标签的结论，非相对人类驾驶。
- A 类训练 loss 中 A1（SFT）与 A2–A4（TPO）损失函数不同，不可直接比较。

---

## 11. 可支撑的论文主张

**强支撑**
- S1：surrogate 偏好优化相对 SFT **无精度增益**；场景感知检验下 A1–A4 **不可区分**（p≥0.36，CI 跨 0）。⚠️ 逐样本检验会误判为"显著"，论文须用场景感知统计。
- S2：模型**整类丢弃转向动作**（全部 20 个 eval 输出 VEER 0 次，`raw_text` 亦 0/3600；28.9% 标签含转向；52/52 未转向）与**几乎从不刹车**（GT 停车样本 y6 0.44m vs 模型 11.3–14.3m）；塌缩在 9 个 held-out 场景**全部 100%**（每场景 60/60），与场景无关，极其稳健。
- S3：**主导误差是纵向（刹车）**：GT 刹车样本 ADE 10.1–11.2m ≈ 2× 均值；转向样本仅 ~5.0m。
- S4：BEV 是 RAT **输出合规性**的必要输入（parse 1.00→0.61，场景引用 1.00→0.51）。
- S5：Action 层独立贡献轨迹精度（去掉 ADE +22%，延迟 +25ms）。
- S6：think 为**复述式**（85.4% 8-gram 逐字来自输入；A1/A2/A4 完全一致，即由输入决定、不随训练权重变化），不代表机动推理。

**弱支撑（需复测）**
- W1 "偏好优化优于 SFT" → 需真实 reward rollout + 更大预算。
- W2 "光照鲁棒性排序" → 需 ≥10 场景/类。
- W3 "语音模态价值" → 需真实音频编码器。

---

## 12. 论文结果章节结构建议

建议顺序（按正向效应与稳健性排序）：

1. **先立 RAT 结构**：用 C 组证明动作层的独立价值（S5，+22% 精度、近零延迟代价）。
2. **再揭行为塌缩**：用 §2/§3 的塌缩三层证据 + 误差归因，说明当前模型的真实局限（S2/S3）——这是**最诚实、最有信息量**的发现，且极其稳健（9/9 场景）。
3. **合规性 vs 精度**：用 B 组 + D 组合并陈述 BEV/Talk2BEV 的作用（S4），强调"合规性而非精度"。
4. **负结果**：A 组 surrogate 偏好无增益（S1），并展示"逐样本 vs 场景感知"统计的对比，作为方法学贡献。
5. **机制**：think 复述（S6）串联起"为何 BEV 只影响合规、为何偏好训练无效、为何会塌缩"。

汇报主线：*DriveTDPA 通过 RAT 分层把环境理解、动作决策与连续轨迹连接起来；动作层有独立价值，但当前 1B/200 步预算下模型尚未学会"何时转弯、何时停车"，BEV/Talk2BEV 目前主要保证输出合规而非轨迹精度。*

## 14. 后续实验建议（按收益排序）

1. **优先解决"不会停车/刹车"**：对停车/减速样本过采样 + 显式 DECELERATE/STOP 动作监督（当前最高收益）。
2. 对转向样本过采样，或引入类别平衡损失（对抗 60.6% ACCELERATE 多数类）。
3. 训练步数 200 → 1000+；偏好对改**真实 reward rollout**。
4. 1B → 更大 backbone 或加规划专用 head。
5. 条件鲁棒性单独建 ≥10 场景/类的 held-out。
