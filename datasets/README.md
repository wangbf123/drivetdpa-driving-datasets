# Dataset Releases

All official releases are CARLA-derived. Large files live in object storage; each subdirectory documents a logical release and links its manifest.

- `carla/`: synchronized sensors, Autoware, BEV, Talk2BEV and DriveTDPA records.
- `preference/`: candidates and selected pairs from CARLA-frame rollouts.
- `closed_loop/`: control-to-next-frame episodes and evaluation outcomes.
